## 🧠 Concept Explanation

Residual Networks (ResNets) solve the degradation problem that appears when very deep plain networks are trained: accuracy saturates and then degrades even though the deeper model should be able to represent the shallower one. The core idea is to let each layer learn a residual function F(x) = H(x) – x instead of the full mapping H(x). By adding the original input x back to the output of a few stacked layers via a shortcut (skip) connection, the network only needs to model the difference. If the optimal mapping is the identity, the residual can be driven to zero, which is far easier for gradient‑based optimization than learning the identity from scratch. During back‑propagation the gradient flows directly through the shortcut, preserving magnitude and preventing vanishing gradients. This enables training of hundreds or even thousands of layers. In practice a residual block consists of two or three convolutions with batch normalization and ReLU, followed by an element‑wise addition of the block’s input. When dimensions change, a 1×1 projection shortcut matches shapes. The result is faster convergence, higher accuracy, and a modular building block that underpins modern architectures such as ResNeXt, DenseNet, and Vision Transformers. Empirically, ResNets achieve state‑of‑the‑art results on ImageNet with far fewer parameters than comparable plain nets.

---

## ✅ Key Points

- Skip connections add the block input to its output, letting layers learn residuals.
- Gradients propagate unchanged through shortcuts, solving vanishing‑gradient issues.
- Identity mapping is easy to learn (just push residual to zero).
- Projection shortcuts (1×1 conv) handle dimension mismatches.
- Residual blocks enable training of extremely deep networks (100+ layers).


---

## ⚠️ Common Mistakes

- Forgetting to match tensor shapes before the element‑wise addition.
- Using too many layers without proper initialization, causing training instability.
- Treating the shortcut as a learnable weight instead of a fixed identity (or 1×1 projection).
