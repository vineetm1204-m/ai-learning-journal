# Day 96 — Convolutional layers: filters, stride, padding

## 🧠 Concept Explanation

Convolutional layers are the workhorse of modern computer vision. Instead of learning a separate weight for every input pixel, a convolution slides a small learnable kernel (filter) across the image, computing a dot product at each position. This weight sharing dramatically reduces parameters and forces the network to detect the same pattern—edges, textures, shapes—anywhere in the spatial domain. The filter size (e.g., 3×3) determines the receptive field of a single output neuron. Stride controls how many pixels the filter jumps each step; a stride of 1 yields dense, overlapping outputs, while stride 2 halves the spatial resolution, providing a built‑in down‑sampling. Padding adds extra border pixels (usually zeros) around the input so that the output can retain the same spatial dimensions as the input, which is convenient for stacking many layers without shrinking the feature map. The output depth equals the number of filters, each learning a distinct feature detector. By stacking multiple convolutional layers, the network builds a hierarchy: early layers capture simple edges, deeper layers compose them into object parts and whole objects. This locality, translation invariance, and parameter efficiency make convolutions the default choice for image, video, and even audio data.

---

## ✅ Key Points

- Filters (kernels) share weights across spatial locations, reducing parameters.
- Stride determines step size; stride > 1 downsamples the feature map.
- Padding (often zero) preserves spatial dimensions and controls border effects.
- Output depth = number of filters, each learning a different feature.
- Stacking convolutions creates hierarchical representations from edges to objects.

## 🏗️ Diagram / Formula

```
Input (H×W×C_in)
   │
   ├─ Pad (p) → (H+2p)×(W+2p)×C_in
   │
   ├─ Convolve with K filters (F×F×C_in) stride s
   │
   └─ Output (H_out×W_out×K)
   where H_out = floor((H + 2p - F)/s) + 1
```

## 💡 Real-World Analogy

A convolutional filter is like a flashlight with a shaped stencil: you slide it over a wall painting, and wherever the stencil matches a pattern, the light shines brightly, revealing that feature everywhere on the wall.

---

## ⚠️ Common Mistakes

- Forgetting to adjust padding when changing stride, causing unexpected size reductions.
- Using too large a filter (e.g., 7×7) early on, which increases parameters and loses fine details.
- Assuming the number of input channels must equal the number of filters; they are independent.
