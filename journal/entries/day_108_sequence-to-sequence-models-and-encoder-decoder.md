## 🧠 Concept Explanation

Sequence-to-sequence (seq2seq) models learn to map an input sequence of variable length to an output sequence of possibly different length. The architecture consists of two recurrent neural networks: an encoder that reads the source tokens one by one and compresses the entire sequence into a fixed‑size context vector (or a set of hidden states), and a decoder that generates the target tokens step by step conditioned on that context. During training, teacher forcing feeds the ground‑truth previous token to the decoder, while at inference the decoder uses its own predictions. Attention mechanisms later augment the basic design by allowing the decoder to look back at all encoder hidden states, solving the bottleneck of a single vector and improving long‑range dependencies. Seq2seq underpins machine translation, text summarization, speech recognition, and code generation. Modern variants replace RNNs with Transformers, but the encoder‑decoder paradigm remains the same: encode the input into a representation, then decode it into the desired output sequence. The loss is typically cross‑entropy summed over each target position, and gradients flow through both encoder and decoder. Beam search or sampling is used at inference to explore multiple hypotheses. Variants such as bidirectional encoders, stacked layers, and residual connections improve capacity. The introduction of self‑attention in Transformers eliminates recurrence, enabling parallel training and better scaling to long sequences.

---

## ✅ Key Points

- Encoder compresses variable‑length input into a context representation.
- Decoder generates output token‑by‑token conditioned on the context.
- Teacher forcing is used during training; inference uses autoregressive decoding.
- Attention lets the decoder attend to all encoder states, alleviating the bottleneck.
- Modern seq2seq often replaces RNNs with Transformer encoder‑decoder blocks.

---

## ⚠️ Common Mistakes

- Using only the final encoder hidden state for long sequences, causing information loss.
- Forgetting to mask padding tokens in the loss, leading to noisy gradients.
- Training without teacher forcing then expecting stable convergence.
