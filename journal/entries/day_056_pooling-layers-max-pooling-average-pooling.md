# Day 56 — Pooling layers: max pooling, average pooling

> 📅 August 23, 2026

## 🧠 Concept Explanation

Pooling layers are a core building block in convolutional neural networks that reduce the spatial dimensions of feature maps while preserving the most salient information. After a convolution produces a high‑resolution activation map, a pooling operation slides a fixed‑size window (e.g., 2×2) across the map with a given stride, summarizing the values inside each window into a single number. Max pooling selects the maximum activation, which highlights the strongest response such as an edge or texture, and provides a form of translation invariance because small shifts of the pattern do not change the maximum. Average pooling computes the mean of the window, yielding a smoother representation that can be useful when the overall intensity matters more than a single peak. Both variants dramatically cut the number of parameters and computations in subsequent layers, helping to prevent overfitting and allowing deeper architectures. Pooling also expands the effective receptive field of later neurons without adding learnable weights. In practice, max pooling is the default for vision tasks, while average pooling appears in architectures like ResNet’s final global average pooling before the classifier. Choosing window size, stride, and padding controls the trade‑off between spatial resolution and abstraction. Typical configurations use a 2×2 window with stride 2, halving height and width, though larger windows or overlapping strides can be employed for finer control.

---

## ✅ Key Points

- Reduces spatial dimensions while keeping important features.
- Max pooling picks the maximum value in each window; average pooling computes the mean.
- Provides translation invariance and expands receptive field without extra parameters.
- Commonly uses a 2×2 window with stride 2, halving height and width.
- Choice of pooling type influences downstream task performance (e.g., max for detection, average for classification).

## 💡 Real-World Analogy

Like downsampling a high‑resolution photo to a thumbnail: max pooling keeps the brightest pixel in each block, while average pooling blends the block into a single tone.

---

## ⚠️ Common Mistakes

- Using pooling after every convolution, discarding too much spatial detail.
- Forgetting that pooling has no learnable parameters, so it cannot be “trained” to adapt.
- Assuming max pooling always outperforms average pooling; the best choice depends on the task.
