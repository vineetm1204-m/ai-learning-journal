## 🧠 Concept Explanation

Activation functions introduce non-linearity into neural networks, enabling them to learn complex patterns beyond simple linear relationships. Sigmoid squashes inputs to (0,1), making it suitable for binary classification outputs but prone to vanishing gradients for large magnitudes. Tanh maps to (-1,1), centering outputs around zero which often speeds up convergence compared to sigmoid. ReLU (Rectified Linear Unit) outputs max(0,x), providing sparse activation and mitigating vanishing gradients for positive inputs, though it can suffer from 'dead neurons' when inputs are consistently negative. Leaky ReLU addresses this by allowing a small positive slope (e.g., 0.01) for negative inputs, keeping gradients alive. GELU (Gaussian Error Linear Unit) weights inputs by their cumulative Gaussian distribution, offering a smooth, probabilistic interpretation that has become standard in modern Transformers. Choosing the right activation depends on the network depth, task, and computational budget; ReLU variants are default for hidden layers in CNNs, while GELU dominates in large language models.

---

## ✅ Key Points

- Sigmoid and tanh saturate for large |x|, causing vanishing gradients in deep networks.
- ReLU is computationally cheap and avoids saturation for positive values but can create dead neurons.
- Leaky ReLU and parametric variants (PReLU) keep small gradients flowing for negative inputs.
- GELU's smooth curvature and probabilistic grounding improve performance in deep Transformer architectures.
- Activation choice interacts with weight initialization and normalization; always pair them thoughtfully.

## 🏗️ Diagram / Formula

```
Sigmoid:  σ(x) = 1 / (1 + exp(-x))
Tanh:     tanh(x) = (exp(x) - exp(-x)) / (exp(x) + exp(-x))
ReLU:     ReLU(x) = max(0, x)
LeakyReLU: LReLU(x) = x if x>=0 else αx (α≈0.01)
GELU:     GELU(x) = 0.5 * x * (1 + tanh(√(2/π) * (x + 0.044715 * x^3)))
```

## 💡 Real-World Analogy

Activation functions are like adjustable valves in a plumbing system: they control how much signal (water) passes through based on the pressure (input value), and different valve designs (sigmoid, ReLU, etc.) handle high pressure, backflow, or fine-tuning differently.

---

## ⚠️ Common Mistakes

- Using sigmoid/tanh in deep hidden layers without residual connections, leading to vanishing gradients.
- Forgetting to set a non-zero negative slope in Leaky ReLU, effectively reverting to standard ReLU.
- Applying ReLU after batch normalization without considering that BN can produce negative values, which ReLU then zeros out.
