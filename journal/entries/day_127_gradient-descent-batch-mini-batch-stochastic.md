## 🧠 Concept Explanation

Gradient descent is the workhorse optimizer that iteratively moves model parameters toward lower loss. In batch gradient descent the gradient is computed on the entire training set, giving a precise but expensive direction; the update is stable and can use larger learning rates, yet each step requires a full pass over all data. Stochastic gradient descent (SGD) takes the opposite extreme: it estimates the gradient from a single randomly chosen example, producing a noisy but cheap update that enables frequent parameter changes and often escapes shallow local minima. Mini‑batch gradient descent sits in between, averaging gradients over a small subset (typically 32‑256 samples). This reduces variance compared with pure SGD while keeping computation tractable on GPUs. All three share the same update rule θ ← θ − η ∇̂J(θ), where ∇̂J is the gradient estimate. The choice trades off convergence speed, hardware utilization, and generalization; mini‑batch is the default in modern deep learning because it balances statistical efficiency with parallel throughput. Practitioners often tune the mini‑batch size and learning rate together; larger batches permit higher learning rates but may degrade generalization, while very small batches increase noise and can slow convergence. Adaptive methods such as Adam or RMSProp build on these gradient estimates, scaling updates per parameter to further improve stability.

---

## ✅ Key Points

- Batch GD uses the full dataset per update → low variance, high compute.
- SGD uses one sample per update → high variance, low compute, frequent updates.
- Mini‑batch GD averages over a small subset → balances variance and hardware efficiency.
- All variants share the same parameter update rule θ ← θ − η ∇̂J(θ).
- Choice of batch size interacts with learning rate and affects generalization.

---

## 🏗️ Diagram / Formula

```
θ_{t+1} = θ_t - η * (1/|B|) Σ_{i∈B} ∇_θ L(x_i, y_i; θ_t)
B = full set (batch), single sample (SGD), or mini‑batch
```

---

## 💡 Real-World Analogy

Like a hiker descending a mountain: batch GD surveys the entire terrain before each step, SGD feels the slope under one foot, and mini‑batch checks a small patch around the current position.

---

## ⚠️ Common Mistakes

- Using too large a batch size without adjusting the learning rate, causing poor generalization.
- Setting the learning rate too high for SGD, leading to divergence.
- Forgetting to shuffle data each epoch, introducing bias in mini‑batch gradients.
