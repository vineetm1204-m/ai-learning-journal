## 🧠 Concept Explanation

Graph Neural Networks (GNNs) extend deep learning to data that naturally lives on graphs — nodes connected by edges. Instead of treating each sample independently, a GNN learns a representation for every node by iteratively aggregating information from its neighbors. At each layer, a node's feature vector is updated by a differentiable function (often a neural network) that combines its own current representation with a permutation‑invariant aggregation (sum, mean, max) of its neighbors' representations. This message‑passing process lets the model capture both local structure (who is connected to whom) and global patterns (community roles, graph‑level properties). After several layers, the final node embeddings can be used for node classification, link prediction, or pooled into a graph‑level vector for graph classification. Because the same parameters are shared across all nodes, GNNs generalize to unseen graphs of varying size. Popular variants include Graph Convolutional Networks (GCN), GraphSAGE, and Graph Attention Networks (GAT), each differing in how they aggregate and weight neighbor messages.

---

## ✅ Key Points

- GNNs operate on graph-structured data using message passing between nodes.
- Node embeddings are updated by aggregating neighbor features with a shared neural network.
- Aggregation functions must be permutation invariant (sum, mean, max).
- Multiple layers allow information to propagate over longer distances in the graph.
- Common architectures: GCN (spectral convolution), GraphSAGE (sampling), GAT (attention).

## 🏗️ Diagram / Formula

```
Layer t:
  h_i^{(t)} = σ( W^{(t)} · AGG( { h_j^{(t-1)} | j ∈ N(i) } ∪ { h_i^{(t-1)} } ) )

AGG = SUM / MEAN / MAX
σ = non‑linearity (ReLU)
W^{(t)} = learnable weight matrix
```

## 💡 Real-World Analogy

Think of a social network where each person updates their opinion by listening to the average opinion of their friends; after several rounds, everyone's view reflects the overall community structure.

---

## ⚠️ Common Mistakes

- Using a non‑permutation‑invariant aggregation (e.g., concatenation) which breaks graph isomorphism invariance.
- Stacking too many layers, causing over‑smoothing where all node embeddings become indistinguishable.
- Ignoring edge features or directionality when the task requires them, limiting model expressiveness.
