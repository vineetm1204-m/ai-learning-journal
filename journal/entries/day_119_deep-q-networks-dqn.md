## 🧠 Concept Explanation

Deep Q-Networks (DQN) combine Q-learning with deep neural networks to handle high-dimensional state spaces like raw pixels. Traditional Q-learning stores a table of state-action values, which is infeasible for complex environments. DQN replaces the table with a neural network that approximates the Q-function, mapping states to action values. Two key innovations stabilize training: experience replay and a target network. Experience replay stores transitions (state, action, reward, next state) in a buffer and samples mini-batches randomly, breaking correlations between consecutive samples and improving data efficiency. The target network is a copy of the main network with frozen weights, used to compute the target Q-values for the Bellman update. Its weights are periodically copied from the main network, preventing the moving-target problem that causes divergence. During training, the agent selects actions via an epsilon-greedy policy, balancing exploration and exploitation. The loss is the mean squared error between the predicted Q-value and the target: r + gamma * max_a' Q_target(s', a'). DQN achieved human-level performance on many Atari games, proving deep RL can learn directly from pixels.

---

## ✅ Key Points

- Neural network approximates Q-function for high-dimensional states
- Experience replay decorrelates samples and reuses past transitions
- Target network provides stable Bellman targets by freezing weights
- Epsilon-greedy policy balances exploration vs. exploitation
- Loss minimizes TD error between predicted and target Q-values

## ⚠️ Common Mistakes

- Forgetting to update the target network periodically, causing unstable targets
- Using a replay buffer that is too small, leading to correlated samples
- Not annealing epsilon properly, resulting in insufficient exploration early or excessive randomness late
