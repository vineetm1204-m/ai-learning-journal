## 🧠 Concept Explanation

The Transformer replaces recurrence and convolution with pure self‑attention, allowing every token to directly attend to all others in parallel. An input sequence is first turned into token embeddings, then enriched with positional encodings so the model knows order. The encoder stack consists of N identical layers; each layer has a multi‑head self‑attention sub‑layer followed by a position‑wise feed‑forward network, both wrapped in residual connections and layer normalization. The decoder mirrors the encoder but adds a second multi‑head attention block that attends to the encoder’s output, enabling conditional generation. Because attention weights are computed by scaled dot‑product of queries, keys, and values, the model can learn long‑range dependencies without vanishing gradients. Training uses teacher forcing and a cross‑entropy loss, while inference typically employs autoregressive decoding with beam search or sampling. The architecture’s parallelism and ability to capture global context made it the foundation for BERT, GPT, and most modern large language models. Self‑attention computes a weighted sum of value vectors where the weights reflect how relevant each key is to a given query, enabling dynamic routing of information. Multi‑head attention repeats this process with different learned projections, letting the model capture diverse relational patterns simultaneously. Positional encodings can be fixed sinusoidal functions or learned embeddings, both providing the sequence order that pure attention lacks. Residual connections and layer normalization stabilize deep stacks, allowing dozens of layers to be trained effectively. The decoder’s masked self‑attention prevents future tokens from influencing current predictions, preserving the autoregressive property.

## ✅ Key Points

- Self‑attention lets every token see all others in one step.
- Multi‑head attention captures multiple relation types simultaneously.
- Positional encodings inject sequence order into a permutation‑invariant model.
- Encoder‑decoder stacks with residual connections and layer norm enable deep training.
- Masked attention in the decoder enforces autoregressive generation.

## 🏗️ Diagram / Formula

```
Input -> Embedding -> Positional Encoding -> Encoder (N layers) -> Decoder (N layers) -> Output
Encoder Layer: Multi-Head Self-Attention -> Add & Norm -> Feed-Forward -> Add & Norm
Decoder Layer: Masked Multi-Head Self-Attention -> Add & Norm -> Encoder-Decoder Attention -> Add & Norm -> Feed-Forward -> Add & Norm
```

## 💡 Real-World Analogy

Imagine a round‑table discussion where each participant instantly hears everyone else’s thoughts and can weigh their relevance before speaking, rather than waiting for a linear chain of whispers.

---

## ⚠️ Common Mistakes

- Forgetting to mask future tokens in decoder self‑attention, causing information leakage.
- Using a single attention head and expecting the model to capture diverse dependencies.
- Omitting positional encodings, which makes the model treat the input as a bag of tokens.
