# Day 87 — Backpropagation intuition and the chain rule

## 🧠 Concept Explanation

Backpropagation is the algorithm that computes the gradient of a loss function with respect to every weight in a neural network. During the forward pass, inputs flow through layers, each applying a linear transform followed by a non‑linearity, producing a prediction. The loss measures how far this prediction is from the target. To improve the model we need to know how each weight contributed to the error. The chain rule from calculus lets us decompose the derivative of the loss with respect to a weight into a product of local derivatives: the derivative of the loss w.r.t. the layer's output, times the derivative of the output w.r.t. its pre‑activation, times the derivative of the pre‑activation w.r.t. the weight. By traversing the computational graph backward — from loss to input — we reuse intermediate gradients, avoiding redundant computation. This reverse‑mode automatic differentiation yields the exact gradient for every parameter in time proportional to the forward pass. The gradients are then used by an optimizer (e.g., SGD, Adam) to update weights, iteratively reducing the loss.

---

## ✅ Key Points

- Forward pass computes activations; loss quantifies error.
- Chain rule breaks global gradient into local Jacobian products.
- Reverse traversal reuses intermediate derivatives (dynamic programming).
- Gradients flow backward through non‑linearities via their derivatives.
- Optimizer uses gradients to update parameters toward lower loss.

## 🏗️ Diagram / Formula

```
Input --> [Linear] --> [ReLU] --> [Linear] --> Loss
        ^          ^          ^          ^
        |          |          |          |
   Gradients <--- Backward <--- Backward <--- Backward
```

## ⚠️ Common Mistakes

- Forgetting to multiply by the derivative of the activation function during back‑prop.
- Accumulating gradients incorrectly when a variable is used in multiple paths (missing sum).
- Using the same learning rate for all layers without considering gradient scale differences.
