# Day 45 — Gradient Descent: batch, mini-batch, stochastic

> 📅 August 10, 2026

---

## 🧠 Concept Explanation

Gradient descent iteratively updates model parameters by moving opposite to the loss gradient. Batch gradient descent computes the gradient over the entire training set each step, yielding a precise but computationally expensive and memory-intensive update. Stochastic gradient descent (SGD) uses a single randomly chosen example per update, making iterations fast and enabling online learning, but the gradient estimate is noisy, causing oscillations and slower convergence near minima. Mini-batch gradient descent strikes a practical balance: it computes the gradient over a small subset (typically 32–512 samples), reducing variance compared to SGD while fitting in GPU memory and allowing highly parallelized matrix operations. This variant is the de facto standard for deep learning. Smaller batches introduce beneficial noise that can act as implicit regularization, often improving generalization. However, learning rate must be adapted to batch size — larger batches typically tolerate higher learning rates. Momentum, adaptive methods (Adam, RMSprop), and learning rate schedules further accelerate convergence across all three variants.

---

## ✅ Key Points

- Batch GD gives exact gradient but scales poorly with dataset size.
- SGD updates per sample, high variance, enables online learning.
- Mini-batch GD reduces variance vs SGD and leverages GPU parallelism.
- Smaller batches often generalize better due to noise-induced regularization.
- Learning rate must be tuned per batch size; larger batches may need larger LR.

---

## 🏗️ Diagram / Formula

```
Batch GD:      θ ← θ - η ∇L(θ)        (∇L averaged over all N samples)
SGD:           θ ← θ - η ∇L_i(θ)      (∇L from single sample i)
Mini-batch:    θ ← θ - η (1/B) Σ ∇L_j(θ)  (average over B samples)
```

---

## 💡 Real-World Analogy

Descending a foggy mountain: batch GD surveys the entire slope before each step; SGD steps based only on the ground beneath one foot; mini-batch GD checks a small patch around you to decide the next move.

---

## ⚠️ Common Mistakes

- Using batch gradient descent on large datasets, causing out-of-memory errors.
- Keeping the same learning rate when changing batch size without scaling.
- Failing to shuffle data before creating mini-batches, leading to correlated gradients.
