# Day 44 — Loss functions: MSE, Cross-Entropy, Huber loss

> 📅 August 09, 2026

## 🧠 Concept Explanation

Loss functions quantify how far a model’s predictions are from the true targets, turning the training objective into a scalar that optimizers can minimize. Mean Squared Error (MSE) averages the squared differences, penalizing large errors heavily and producing smooth gradients everywhere, which makes it a natural fit for regression where the output is continuous. Cross‑Entropy (or log loss) measures the divergence between the predicted probability distribution and the true one‑hot label; it grows sharply when the model assigns low probability to the correct class, providing strong gradient signals for classification tasks. Huber loss blends the best of both worlds: it behaves like MSE for small residuals (quadratic) and switches to a linear penalty for large residuals, reducing the influence of outliers while keeping differentiability at the transition point. Choosing the right loss aligns the geometry of the error surface with the problem’s noise characteristics—Gaussian noise favors MSE, label noise or heavy‑tailed errors favor Huber, and discrete class predictions demand cross‑entropy. In practice, the loss also determines the scale of gradients, affecting learning‑rate selection and convergence speed. When implementing, ensure the loss matches the output activation—sigmoid or softmax pairs with cross‑entropy, while linear outputs pair with MSE or Huber. Monitoring loss curves helps diagnose under‑fitting, over‑fitting, or gradient explosion early in training.

---

## ✅ Key Points

- MSE penalizes squared error, ideal for Gaussian noise regression.
- Cross‑Entropy measures probability divergence, standard for classification.
- Huber loss is quadratic near zero and linear beyond a delta, robust to outliers.
- Loss choice dictates gradient magnitude and influences learning‑rate tuning.
- Matching loss to output activation (e.g., softmax + cross‑entropy) avoids gradient mismatch.

## 🏗️ Diagram / Formula

```
MSE      = (1/n) Σ (y_i - ŷ_i)^2
CrossEnt = - Σ y_i log(ŷ_i)
Huber    = { 0.5*(y-ŷ)^2                 if |y-ŷ| ≤ δ
           { δ*|y-ŷ| - 0.5*δ^2           otherwise
```

## 💡 Real-World Analogy

Choosing a loss is like picking a scoring rule for a game: MSE penalizes the square of the distance from the target, cross‑entropy rewards confidence in the correct answer, and Huber acts like a referee who ignores extreme fouls but still counts small mistakes.

---

## ⚠️ Common Mistakes

- Using MSE with softmax outputs for classification.
- Forgetting to reduce cross‑entropy over the batch (sum vs. mean) causing unstable gradients.
- Setting Huber’s δ too large, making it behave like MSE and losing robustness.
