# Day 97 — Pooling layers: max pooling, average pooling

> 📅 October 26, 2026

---

## 🧠 Concept Explanation

Pooling layers reduce the spatial dimensions of feature maps while preserving the most salient information. In a convolutional neural network, after several convolutional layers the activations can become large and redundant. A pooling window (often 2×2) slides over each channel with a fixed stride, summarizing the values inside. Max pooling selects the maximum activation, emphasizing the strongest response such as an edge or texture. Average pooling computes the mean, providing a smoother representation that can be useful for tasks like global average pooling before a classifier. Both operations are parameter‑free, so they add no learnable weights and incur minimal computation. By discarding precise location details, pooling introduces translation invariance: small shifts in the input produce similar pooled outputs. This also acts as a regularizer, reducing over‑fitting. Modern architectures sometimes replace pooling with strided convolutions, yet pooling remains a simple, effective down‑sampling tool, especially in early network stages where it quickly expands the receptive field. During back‑propagation, gradients are routed only through the selected maximum locations for max pooling, while average pooling distributes the gradient uniformly across the window. This difference influences how feature detectors learn: max pooling encourages sparse, high‑activation pathways, whereas average pooling promotes distributed representations. Choosing between them depends on the task; for example, object detection often benefits from max pooling's sharpness, while segmentation may prefer average pooling's smoother gradients. Additionally, adaptive pooling layers let the network output a fixed spatial size regardless of input resolution, simplifying fully‑connected heads.

---

## ✅ Key Points

- Pooling reduces spatial size without learnable parameters.
- Max pooling keeps the strongest activation; average pooling computes the mean.
- Both provide translation invariance and act as regularizers.
- Stride and window size control down‑sampling factor.
- Adaptive pooling can produce fixed‑size outputs for any input resolution.

## 💡 Real-World Analogy

Pooling is like summarizing a page of text by keeping only the most important keyword (max pooling) or the average sentiment of each paragraph (average pooling).

---

## ⚠️ Common Mistakes

- Using too large a pooling window, losing critical detail.
- Forgetting that max pooling discards gradient information for non‑max positions.
- Applying pooling after every convolution, which can overly reduce resolution early.
