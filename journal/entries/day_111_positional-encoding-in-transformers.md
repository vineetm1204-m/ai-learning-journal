# Day 111 — Positional encoding in Transformers

> 📅 November 10, 2026

---

## 🧠 Concept Explanation

Positional encoding injects information about the order of tokens into the otherwise permutation‑invariant Transformer. Since self‑attention treats the input as a set, the model cannot distinguish “cat chases mouse” from “mouse chases cat” without an explicit position signal. The original paper proposes a deterministic sinusoidal scheme: for each position pos and dimension i, the encoding uses sin(pos / 10000^{2i/d_model}) for even i and cos for odd i. This choice gives two useful properties. First, the wavelengths form a geometric progression, allowing the model to attend to both very short and very long relative distances. Second, for any fixed offset k, the encoding at position pos+k can be expressed as a linear function of the encoding at pos, so the network can learn to attend by relative position without ever seeing absolute indices. In practice the encodings are added to the token embeddings before the first attention layer. Learned positional embeddings are an alternative; they are initialized randomly and updated during training, which can work better when sequence lengths exceed the pre‑defined maximum of the sinusoidal table. Both approaches give the model a notion of sequence order while keeping the architecture fully parallelizable.

---

## ✅ Key Points

- Transformers are permutation‑invariant; positional encodings provide order information.
- Sinusoidal encodings use sine/cosine with geometrically spaced wavelengths.
- Relative positions become linearly related, enabling the model to learn relative attention.
- Encodings are added to token embeddings before the first attention layer.
- Learned positional embeddings are a trainable alternative that can handle longer sequences.

---

## 🏗️ Diagram / Formula

```
PE(pos, 2i)   = sin(pos / 10000^{2i/d_model})
PE(pos, 2i+1) = cos(pos / 10000^{2i/d_model})
```

---

## 💡 Real-World Analogy

Like page numbers in a book, positional encodings tell the model which token comes first, second, third, so it can understand the story's sequence.

---

## ⚠️ Common Mistakes

- Forgetting to add positional encodings to the input embeddings, leaving the model order‑agnostic.
- Using a fixed sinusoidal table for sequences longer than the maximum position it was designed for.
- Treating learned positional embeddings as static after initialization instead of allowing them to be updated during training.
