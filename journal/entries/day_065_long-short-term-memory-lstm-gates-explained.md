## 🧠 Concept Explanation

Long Short-Term Memory (LSTM) networks are a type of recurrent neural network designed to capture long-range dependencies by regulating the flow of information through a cell state. At each time step the LSTM receives the current input x_t and the previous hidden state h_{t-1}. Three gates—input, forget, and output—act as differentiable valves that decide what to add, discard, or expose from the cell state c_t. The forget gate f_t = σ(W_f·[h_{t-1}, x_t] + b_f) determines how much of the previous cell memory to keep. The input gate i_t = σ(W_i·[h_{t-1}, x_t] + b_i) and a candidate value ˆc_t = tanh(W_c·[h_{t-1}, x_t] + b_c) propose new information, which is added to the cell state: c_t = f_t ⊙ c_{t-1} + i_t ⊙ ˆc_t. Finally, the output gate o_t = σ(W_o·[h_{t-1}, x_t] + b_o) controls the next hidden state: h_t = o_t ⊙ tanh(c_t). Because gradients can flow unchanged through the additive cell update, LSTMs mitigate the vanishing-gradient problem that plagues vanilla RNNs, enabling them to learn patterns over hundreds of time steps.

---

## ✅ Key Points

- LSTM uses a cell state as a conveyor belt for information.
- Three gates (forget, input, output) regulate reading, writing, and exposing memory.
- Gates are sigmoid-activated, producing values in [0,1] for element-wise multiplication.
- The additive cell update (c_t = f_t ⊙ c_{t-1} + i_t ⊙ ˆc_t) preserves gradient flow.
- LSTMs can learn long-range dependencies far better than vanilla RNNs.

## 💡 Real-World Analogy

Think of the cell state as a notebook you carry across days; the forget gate decides which old notes to erase, the input gate chooses which new notes to write, and the output gate selects which notes to read aloud today.

---

## ⚠️ Common Mistakes

- Confusing the cell state c_t with the hidden state h_t.
- Forgetting that gates output continuous values in [0,1], not binary masks.
- Using vanilla RNN weight initialization for LSTM parameters, causing gate saturation.
