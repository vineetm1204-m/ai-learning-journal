# Day 106 — Long Short-Term Memory (LSTM) gates explained

> 📅 November 04, 2026

## 🧠 Concept Explanation

Long Short-Term Memory (LSTM) networks are a type of recurrent neural network designed to capture long-range dependencies in sequential data. At the heart of each LSTM cell lies a memory cell state that flows through time with minimal alteration, controlled by three gating mechanisms: the forget gate, the input gate, and the output gate. The forget gate decides which information from the previous cell state should be discarded, using a sigmoid activation that outputs values between 0 (completely forget) and 1 (keep). The input gate determines what new information to add to the cell state; it combines a sigmoid gate (which selects values) with a tanh layer (which creates candidate values). The cell state is then updated by element‑wise multiplication of the forget gate with the old state plus the input gate’s candidate values. Finally, the output gate filters the updated cell state through a sigmoid and multiplies it by a tanh of the cell state to produce the hidden state passed to the next time step. This gated architecture allows gradients to flow unchanged across many steps, mitigating the vanishing‑gradient problem that plagues vanilla RNNs.

---

## ✅ Key Points

- Cell state acts as a conveyor belt preserving information across time steps.
- Forget gate uses sigmoid to decide what to erase from the cell state.
- Input gate combines a sigmoid selector with a tanh candidate generator to add new information.
- Output gate controls what part of the cell state becomes the hidden output.
- Gating mechanisms enable stable gradient flow, solving the vanishing‑gradient issue.

## 🏗️ Diagram / Formula

```
          x_t
           |
      +----+----+
      |         |
   [sigmoid]  [tanh]   <-- input gate (i_t) & candidate (g_t)
      |         |
      +----+----+
           |
   f_t = sigmoid(W_f·[h_{t-1}, x_t] + b_f)   <-- forget gate
           |
   C_t = f_t ⊙ C_{t-1} + i_t ⊙ g_t          <-- cell state update
           |
   o_t = sigmoid(W_o·[h_{t-1}, x_t] + b_o)   <-- output gate
           |
   h_t = o_t ⊙ tanh(C_t)                     <-- hidden state
```

## 💡 Real-World Analogy

Think of an LSTM as a librarian who keeps a master ledger (cell state). The forget gate decides which old entries to shred, the input gate chooses new books to catalog, and the output gate selects which summary to hand to the next researcher.

---

## ⚠️ Common Mistakes

- Confusing the hidden state with the cell state and treating them as interchangeable.
- Using ReLU instead of sigmoid/tanh for gates, which breaks the 0‑1 gating behavior.
- Forgetting to initialize the forget gate bias to a positive value (e.g., 1.0) to encourage remembering at the start.
