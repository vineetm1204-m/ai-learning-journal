# Day 109 — Attention mechanisms: self-attention and cross-attention

> 📅 November 08, 2026

---

## 🧠 Concept Explanation

Attention mechanisms let a model decide which parts of an input sequence are most relevant for each output step. In self‑attention, every token in a sequence attends to all other tokens (including itself), producing contextualized representations that capture long‑range dependencies without recurrence. The computation builds three projections — queries (Q), keys (K), and values (V) — from the same input. The attention scores are the scaled dot‑product QKᵀ/√d, passed through softmax to obtain a distribution, then used to weight the V vectors. Cross‑attention follows the same pattern but draws Q from one sequence (e.g., decoder states) while K and V come from another (e.g., encoder outputs), enabling the decoder to focus on relevant encoder positions at each generation step. Both forms are permutation‑equivariant, parallelizable, and form the backbone of Transformers, powering tasks from translation to vision.

---

## ✅ Key Points

- Self‑attention computes relationships within a single sequence using shared Q/K/V projections.
- Cross‑attention mixes two sequences: queries from the target, keys/values from the source.
- Scaled dot‑product (QKᵀ/√d) stabilizes gradients for high‑dimensional vectors.
- Softmax turns raw scores into a probability distribution for weighted value aggregation.
- Multi‑head attention repeats the process in parallel with different learned projections, then concatenates results.

---

## 🏗️ Diagram / Formula

```
Self‑Attention:
  X → Linear → Q, K, V
  Scores = softmax(Q·Kᵀ / √d)
  Output = Scores·V

Cross‑Attention:
  Decoder X → Linear → Q
  Encoder Y → Linear → K, V
  Scores = softmax(Q·Kᵀ / √d)
  Output = Scores·V
```

## 💡 Real-World Analogy

Imagine a round‑table meeting where each participant (token) listens to everyone else’s remarks (keys) before formulating their own contribution (value), weighting each speaker by relevance (attention scores).

---

## ⚠️ Common Mistakes

- Confusing self‑attention with cross‑attention and using the same Q/K/V sources for both.
- Forgetting to scale the dot‑product by √d, causing unstable gradients in deep models.
- Applying a single attention head instead of multi‑head, limiting the model’s ability to capture diverse relations.
