# Day 91 — Feedforward Neural Networks (ANN) architecture

## 🧠 Concept Explanation

A Feedforward Neural Network (FNN), often called a Multilayer Perceptron (MLP), is the foundational architecture of deep learning where information flows strictly in one direction—from input, through hidden layers, to output—without cycles or loops. The network consists of an input layer receiving raw features, one or more hidden layers performing non-linear transformations, and an output layer producing predictions. Each neuron in a layer computes a weighted sum of its inputs, adds a bias term, and passes the result through an activation function (e.g., ReLU, Sigmoid, Tanh). This non-linearity is critical; without it, stacking multiple linear layers would collapse into a single linear model, incapable of learning complex patterns. During training, the network minimizes a loss function (like Cross-Entropy or MSE) using backpropagation combined with gradient descent. Backpropagation efficiently calculates gradients of the loss with respect to every weight by applying the chain rule backward through the network. The depth (number of layers) and width (neurons per layer) control the model's capacity to approximate functions, governed by the Universal Approximation Theorem, which states a network with a single hidden layer of sufficient width can approximate any continuous function. However, deeper networks often learn hierarchical representations more efficiently, making them the standard for modern deep learning tasks.

---

## ✅ Key Points

- Unidirectional flow: Input → Hidden Layers → Output; no feedback loops or recurrence.
- Non-linear activation functions (ReLU, Sigmoid) enable learning complex, non-linear decision boundaries.
- Universal Approximation Theorem guarantees representational capacity with sufficient hidden units.
- Training relies on Backpropagation (gradient calculation) + Optimizer (SGD, Adam) for weight updates.
- Architecture hyperparameters: Depth (layers), Width (neurons), Activation choice, and Regularization (Dropout, BatchNorm).

```
  x1  ----\              h1 = σ(W1*x + b1)          h2 = σ(W2*h1 + b2)          ŷ = softmax(W3*h2 + b3)
  x2  ----/                  |                             |                          |
  x3  ----\                  v                             v                          v
  ... ----/             [Neurons]                      [Neurons]                 [Predictions]

Formula: ŷ = f_L(W_L * f_{L-1}(... f_1(W_1 * x + b_1) ...) + b_L)
```

## 💡 Real-World Analogy

An assembly line in a factory: raw materials (input) pass through a series of specialized workstations (hidden layers), each refining the product, until a finished item (output) emerges at the end; no station sends parts backward.

---

## ⚠️ Common Mistakes

- Using linear activations in hidden layers, collapsing the deep network into a single linear model.
- Ignoring input normalization/standardization, causing unstable gradients and slow convergence.
- Choosing excessively wide/shallow architectures instead of deeper ones, missing hierarchical feature learning.
