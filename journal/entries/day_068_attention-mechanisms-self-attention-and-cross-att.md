# Day 68 — Attention mechanisms: self-attention and cross-attention

> 📅 September 10, 2026

---

## 🧠 Concept Explanation

Attention lets a model weigh the relevance of different parts of its input when producing each output element. In self‑attention, every token in a sequence attends to all other tokens (including itself), computing a weighted sum of value vectors where the weights come from compatibility scores between query and key vectors. This enables the model to capture long‑range dependencies without recurrence. Cross‑attention, by contrast, connects two distinct sequences: queries come from the target (e.g., decoder) while keys and values come from the source (e.g., encoder). The decoder can thus focus on relevant encoder positions at each generation step. Both mechanisms rely on the scaled dot‑product: Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V. Multi‑head attention repeats this process with different learned projections, allowing the model to attend to multiple representation subspaces simultaneously. The result is a set of context vectors that enrich each token with global information, forming the backbone of Transformers and many modern architectures.

---

## ✅ Key Points

- Self‑attention computes relationships within a single sequence.
- Cross‑attention links two separate sequences (e.g., encoder‑decoder).
- Scaled dot‑product attention uses queries, keys, and values.
- Multi‑head attention runs several attention heads in parallel.
- Attention weights are differentiable, enabling end‑to‑end training.

---

## 🏗️ Diagram / Formula

```
Self‑Attention:
  Q = XW_Q   K = XW_K   V = XW_V
  Attn = softmax(Q Kᵀ / √d_k) V

Cross‑Attention:
  Q = DecXW_Q   K = EncXW_K   V = EncXW_V
  Attn = softmax(Q Kᵀ / √d_k) V
```

---

## 💡 Real-World Analogy

Self‑attention is like a group discussion where everyone listens to everyone else before speaking; cross‑attention is a translator who reads the source text (encoder) and, for each word they produce, looks back at the most relevant source words.

---

## ⚠️ Common Mistakes

- Confusing self‑attention with cross‑attention and using the wrong query/key/value sources.
- Forgetting to scale the dot‑product by √d_k, causing gradient instability.
- Treating attention weights as hard alignments instead of soft, differentiable distributions.
