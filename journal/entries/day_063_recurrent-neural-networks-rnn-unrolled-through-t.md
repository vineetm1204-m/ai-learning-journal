# Day 63 — Recurrent Neural Networks (RNN) unrolled through time

> 📅 September 04, 2026

---

## 🧠 Concept Explanation

Recurrent Neural Networks process sequences by maintaining a hidden state that is updated at each time step. When we “unroll” an RNN through time, we create a separate copy of the same cell for every element in the sequence, sharing weights across all copies. The input at step t, x_t, feeds into the cell together with the previous hidden state h_{t‑1}. The cell computes a new hidden state h_t = f(W_h h_{t‑1} + W_x x_t + b) and often produces an output y_t = g(W_y h_t + c). Because the same parameters are reused, the network can handle sequences of arbitrary length while keeping the parameter count constant. Unrolling makes the recurrent computation explicit, turning the cyclic graph into a deep feed‑forward network whose depth equals the sequence length. This view is essential for back‑propagation through time (BPTT), where gradients flow backward across the unrolled steps, allowing the model to learn long‑range dependencies. However, very deep unrollings can suffer from vanishing or exploding gradients, motivating gated architectures such as LSTM and GRU. In practice, we truncate the unrolled graph to a fixed number of steps for memory efficiency, a technique called truncated BPTT. The shared weights also mean that the model learns a single transition function that applies uniformly across time, which is why RNNs excel at tasks like language modeling, speech recognition, and time‑series forecasting.

---

## ✅ Key Points

- Unrolling replicates the same RNN cell for each time step, sharing weights across copies.
- The hidden state h_t carries information from previous steps into the current computation.
- Back‑propagation through time (BPTT) computes gradients by traversing the unrolled graph backward.
- Long unrollings can cause vanishing or exploding gradients, motivating gated cells like LSTM/GRU.
- Truncated BPTT limits the unrolled depth for memory and stability.

## 🏗️ Diagram / Formula

```
h_t = σ(W_h h_{t-1} + W_x x_t + b); y_t = φ(W_y h_t + c)
```

## 💡 Real-World Analogy

An RNN unrolled through time is like a relay race where each runner (time step) passes a baton (hidden state) to the next, using the same baton throughout.

---

## ⚠️ Common Mistakes

- Treating each time step as having independent parameters instead of shared weights.
- Ignoring gradient clipping, leading to exploding gradients in deep unrollings.
- Using a full unroll for very long sequences without truncation, causing out‑of‑memory errors.
