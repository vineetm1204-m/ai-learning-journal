# Day 103 — Object detection: YOLO, R-CNN family overview

> 📅 November 01, 2026

## 🧠 Concept Explanation

Object detection locates and classifies multiple objects in an image. Two dominant families are the R‑CNN series and YOLO. R‑CNN (Regions with CNN features) first proposes ~2 000 region candidates using selective search, warps each to a fixed size, runs a CNN, then classifies with SVMs and refines boxes with a regressor. Fast R‑CNN shares the CNN computation by running the whole image once and extracting region features via ROI pooling. Faster R‑CNN replaces selective search with a Region Proposal Network (RPN) that predicts proposals directly from feature maps, enabling near‑real‑time speeds. YOLO (You Only Look Once) takes a different single‑shot approach: the image is divided into an S×S grid; each cell predicts B bounding boxes, confidence scores, and class probabilities in one forward pass. Later versions (v2‑v8) add anchor boxes, multi‑scale predictions, and feature‑pyramid necks to improve small‑object recall. YOLO favors speed and simplicity, while Faster R‑CNN typically yields higher accuracy on dense or overlapping objects. Modern detectors often blend ideas — e.g., YOLOv5 uses a CSPDarknet backbone and PANet neck similar to Faster R‑CNN’s FPN — showing convergence toward efficient, accurate, end‑to‑end trainable pipelines.

---

## ✅ Key Points

- R‑CNN family evolves from region proposals → shared CNN → learnable RPN for proposals.
- YOLO frames detection as a single regression problem on a grid, predicting boxes and classes simultaneously.
- Fast/Faster R‑CNN use ROI pooling/align to extract fixed‑size features from variable proposals.
- Anchor boxes and multi‑scale feature pyramids (FPN/PANet) are now standard in both families.
- Trade‑off: YOLO favors inference speed; Faster R‑CNN often achieves higher mAP on complex scenes.

## 💡 Real-World Analogy

R‑CNN is like a detective who first marks suspicious areas on a map, then investigates each spot in detail; YOLO is a security guard who scans the whole scene at once and instantly shouts out every threat.

---

## ⚠️ Common Mistakes

- Treating the confidence score as class probability without multiplying by class scores.
- Using the same anchor sizes for all datasets, ignoring object scale distribution.
- Forgetting to apply non‑maximum suppression (NMS) per class, leading to duplicate boxes.
