## 🧠 Concept Explanation

BERT (Bidirectional Encoder Representations from Transformers) is a transformer‑based model that learns contextual word representations by pre‑training on a large corpus using two self‑supervised objectives. The primary objective is masked language modeling (MLM): a random 15 % of input tokens are replaced with a special [MASK] token (or left unchanged or replaced with a random token) and the model must predict the original token IDs from the surrounding context. Because the Transformer encoder attends to all positions simultaneously, each prediction can condition on both left and right context, yielding truly bidirectional representations. The second objective, next sentence prediction (NSP), teaches the model to understand sentence‑level relationships by classifying whether two segments follow each other in the original text. During pre‑training, the input is formatted as “[CLS] segment A [SEP] segment B [SEP]”, where the [CLS] token’s final hidden state aggregates sequence‑level information for downstream classification tasks. After pre‑training, BERT can be fine‑tuned on specific tasks (e.g., sentiment analysis, QA) by adding a task‑specific head and updating all parameters. The masked language modeling objective forces the model to learn deep syntactic and semantic cues, making the resulting embeddings highly transferable. The base version contains 12 encoder layers, 768 hidden units, and 12 attention heads, while the large version doubles these dimensions, enabling richer representations at the cost of more compute.

## ✅ Key Points

- Bidirectional Transformer encoder learns context from both directions.
- Masked Language Modeling predicts randomly masked tokens.
- Next Sentence Prediction teaches sentence‑level coherence.

## 💡 Real-World Analogy

BERT is like a detective who reads a paragraph with some words erased, then uses the surrounding sentences to infer the missing words, learning to understand language deeply.

---

## ⚠️ Common Mistakes

- Assuming BERT only sees left‑to‑right context like a traditional RNN.
- Forgetting to add the [CLS] token when using BERT for classification.
- Using the same learning rate for pre‑training and fine‑tuning without adjustment.
