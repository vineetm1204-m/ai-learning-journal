## 🧠 Concept Explanation

Activation functions introduce non-linearity into neural networks, allowing them to learn complex patterns beyond simple linear relationships. Without them, a deep network would collapse into a single linear transformation regardless of depth. Sigmoid (σ(x) = 1/(1+e⁻ˣ)) squashes inputs to (0,1), historically used for binary classification outputs. However, it suffers from vanishing gradients for large |x| and outputs are not zero-centered, causing zig-zagging optimization. Tanh (tanh(x) = (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ)) maps to (-1,1), zero-centered, easing optimization compared to sigmoid, but still saturates for large magnitudes. ReLU (max(0,x)) is the modern default: computationally cheap, mitigates vanishing gradients for positive inputs, and induces sparsity. Its downside is "dying ReLU" where neurons output zero permanently for negative inputs. Leaky ReLU (max(αx, x), α≈0.01) fixes dying neurons by allowing a small gradient for negative inputs, preserving gradient flow. GELU (xΦ(x), where Φ is Gaussian CDF) weights inputs by their percentile, providing smooth non-linearity that outperforms ReLU in transformers (BERT, GPT). It approximates stochastic regularization and avoids hard thresholding. Choosing an activation depends on architecture: ReLU/Leaky ReLU for CNNs, GELU for transformers, sigmoid/tanh for gating or output layers.

---

## ✅ Key Points

- Non-linearity enables deep networks to approximate complex functions.
- Sigmoid and tanh saturate, causing vanishing gradients; tanh is zero-centered.
- ReLU is fast and sparse but can suffer from dead neurons.
- Leaky ReLU and GELU maintain gradient flow for negative inputs.
- GELU's probabilistic weighting suits transformer architectures.

## 🏗️ Diagram / Formula

```
Sigmoid:  σ(x) = 1 / (1 + exp(-x))
Tanh:     tanh(x) = (exp(x) - exp(-x)) / (exp(x) + exp(-x))
ReLU:     max(0, x)
LeakyReLU: max(0.01x, x)
GELU:     x * Φ(x)  (Φ = Gaussian CDF)
```

## 💡 Real-World Analogy

Activation functions are like light dimmer switches: sigmoid/tanh are smooth sliders that jam at extremes, ReLU is an on/off switch that breaks if stuck off, Leaky ReLU lets a tiny current through when off, and GELU adjusts brightness based on how typical the input level is.

---

## ⚠️ Common Mistakes

- Using sigmoid/tanh in deep hidden layers leading to vanishing gradients.
- Ignoring dying ReLU by not monitoring zero activations or using Leaky ReLU.
- Applying ReLU in transformer models where GELU's smoothness improves convergence.
