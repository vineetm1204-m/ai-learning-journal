# Day 78 — Deep Q-Networks (DQN)

## 🧠 Concept Explanation

Deep Q-Networks (DQN) combine Q-learning with deep neural networks to approximate the optimal action-value function in high-dimensional state spaces. Traditional tabular Q-learning stores a value for every state-action pair, which becomes infeasible when states are raw pixels or continuous vectors. DQN replaces the table with a convolutional neural network (or fully connected net) that takes the state as input and outputs Q-values for all actions. Training uses experience replay: transitions (s, a, r, s') are stored in a buffer and sampled uniformly to break correlation between consecutive samples. A separate target network, whose parameters are copied from the online network every few thousand steps, provides stable targets for the Bellman update. The loss is the mean squared error between the predicted Q(s,a) and the target r + γ max_a' Q_target(s',a'). An ε-greedy policy balances exploration and exploitation. By learning directly from raw observations, DQN achieved human-level performance on many Atari 2600 games, demonstrating that deep function approximation can work with off-policy RL when equipped with replay and target networks.

---

## ✅ Key Points

- Neural network approximates Q(s,a) instead of a lookup table
- Experience replay decorrelates training samples
- Target network stabilizes Bellman targets
- Loss = MSE between online Q and target r + γ max Q_target
- ε-greedy exploration with decaying ε

   |

## 💡 Real-World Analogy

Think of DQN as a chess player who studies a notebook of past games (replay buffer), consults a coach who updates advice only periodically (target network), and uses a mental model (neural net) to evaluate any board position instantly.

---

## ⚠️ Common Mistakes

- Updating the target network every step, causing unstable targets
- Using a too-small replay buffer, leading to correlated samples
- Forgetting to clip rewards or gradients, resulting in exploding values
