# Day 59 — ResNets and skip connections

## 🧠 Concept Explanation

Residual Networks (ResNets) solve the degradation problem that appears when very deep plain networks are trained: accuracy saturates and then degrades despite the network having enough capacity. The key idea is to let each layer learn a residual function F(x) = H(x) - x instead of the full mapping H(x). By adding the input x directly to the output of a few stacked layers via an identity shortcut, the network can easily represent the identity mapping (by driving F(x) to zero) and thus never performs worse than a shallower counterpart. During back‑propagation, the gradient can flow unchanged through the shortcut, mitigating vanishing gradients and enabling training of hundreds or even thousands of layers. The shortcut can be a pure identity (when dimensions match) or a 1×1 projection (when they differ). This design yields faster convergence, higher accuracy, and has become the default backbone for most modern vision models.

---

## ✅ Key Points

- Residual block learns F(x) = H(x) - x, making identity mapping trivial.
- Identity shortcut preserves gradient flow, alleviating vanishing gradients.
- Projection shortcut (1×1 conv) handles dimension changes.
- Enables training of extremely deep networks (100+ layers) with better accuracy.
- Forms the basis for many architectures: ResNeXt, DenseNet, EfficientNet, Vision Transformers.

## 🏗️ Diagram / Formula

```
   x ──► [ conv → BN → ReLU → conv → BN ] ──► + ──► ReLU ──► out
          │                                 ▲
          └────────────── identity ────────┘
```

## 💡 Real-World Analogy

Think of a highway with express lanes that let traffic bypass congested local roads; the shortcut lets information travel quickly across many layers without getting stuck.

---

## ⚠️ Common Mistakes

- Forgetting to match tensor shapes before adding the shortcut, causing runtime errors.
- Using ReLU before the addition, which blocks the identity path for negative values.
- Assuming deeper always means better; without proper regularization, very deep ResNets can still overfit.
