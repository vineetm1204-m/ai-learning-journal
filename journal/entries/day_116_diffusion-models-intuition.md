## 🧠 Concept Explanation

Diffusion models learn to generate data by reversing a gradual noising process. In the forward process, clean data (e.g., an image) is corrupted step‑by‑step with Gaussian noise until it becomes pure noise. This defines a Markov chain where each step adds a small amount of noise according to a fixed schedule. The model is trained to predict the noise added at each step, effectively learning the reverse transition probabilities. During sampling, we start from random noise and iteratively apply the learned denoising network, subtracting the predicted noise to move back toward the data manifold. Because the forward process is tractable and the reverse process is parameterized by a neural network (often a U‑Net with time embeddings), training reduces to a simple mean‑squared error between predicted and actual noise. The result is a generative model that can produce high‑fidelity samples without adversarial training, and it naturally supports conditional generation by feeding extra information (class labels, text embeddings) into the denoiser.

---

## ✅ Key Points

- Forward diffusion adds Gaussian noise in a predefined schedule until data becomes isotropic noise.
- Training objective: predict the added noise at each timestep (score matching / denoising score matching).
- Reverse process uses a neural network (typically a U‑Net) conditioned on timestep to denoise.
- Sampling starts from pure noise and iteratively applies the learned denoiser to generate data.
- No adversarial loss; stable training and high sample quality with flexible conditioning.

## 🏗️ Diagram / Formula

```
Forward:   x_0 -> x_1 -> x_2 -> ... -> x_T  (add noise)
Reverse:   x_T -> x_{T-1} -> ... -> x_0  (denoise with NN)

Denoiser θ(x_t, t) ≈ ε  where x_t = √α_t x_0 + √(1-α_t) ε
```

## 💡 Real-World Analogy

Imagine a photo slowly dissolving into static on an old TV; diffusion models learn to run the static backward, reconstructing the original picture frame by frame.

---

## ⚠️ Common Mistakes

- Treating the noise schedule as a learnable parameter instead of fixing it, which destabilizes training.
- Ignoring the timestep embedding, causing the denoiser to be unable to adapt its behavior across noise levels.
- Using too few diffusion steps at inference, leading to poor sample quality despite a well‑trained model.
