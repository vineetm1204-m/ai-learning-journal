# Day 72 — GPT and autoregressive language modeling

> 📅 September 18, 2026

## 🧠 Concept Explanation

Autoregressive language modeling predicts the next token given all previous tokens, forming a probability distribution over the vocabulary at each step. GPT (Generative Pre‑trained Transformer) stacks many decoder‑only Transformer layers, each containing masked self‑attention that prevents a token from attending to future positions, and a feed‑forward network. During pre‑training the model maximizes the likelihood of massive text corpora by minimizing cross‑entropy loss for every next‑token prediction. At inference time the model generates text token by token, feeding each newly generated token back as input. The causal masking guarantees that the conditional distribution factorizes as the product of per‑step probabilities, which is exactly the chain rule of probability for sequences. Because the same parameters are reused at every position, the model learns reusable linguistic patterns—syntax, semantics, world knowledge—without any explicit supervision. Scaling depth, width, and data yields emergent abilities such as few‑shot reasoning, code generation, and instruction following. Fine‑tuning on curated datasets or using reinforcement learning from human feedback aligns the raw next‑token predictor with user intent, turning a statistical language model into a helpful assistant. The model’s ability to condition on arbitrarily long contexts is limited by the fixed context window, prompting research into recurrence, retrieval, and sparse attention mechanisms.

## ✅ Key Points

- Causal masking enforces autoregressive factorization.
- Decoder‑only Transformer shares parameters across positions.
- Pre‑training uses next‑token cross‑entropy on massive corpora.
- Generation proceeds token‑by‑token, feeding predictions back.
- Scaling yields emergent few‑shot and reasoning capabilities.

## 💡 Real-World Analogy

Like a storyteller who can only speak the next word after hearing the whole story so far, GPT predicts each word based on everything that came before.

---

## ⚠️ Common Mistakes

- Treating GPT as a bidirectional encoder like BERT.
- Ignoring the fixed context window and feeding arbitrarily long prompts.
- Assuming the model “understands” rather than modeling statistical regularities.
