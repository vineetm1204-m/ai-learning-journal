# Day 35 — Graph Neural Networks (GNNs) basics

## 🧠 Concept Explanation

Graph Neural Networks (GNNs) extend deep learning to data that lives on irregular structures — graphs — where entities (nodes) and their relationships (edges) carry the signal. Instead of applying a fixed convolution kernel on a grid, a GNN learns a function that aggregates information from a node's local neighborhood. At each layer, every node updates its hidden representation by combining its own previous state with messages received from adjacent nodes, typically through a permutation‑invariant aggregation such as sum, mean, or max. This message‑passing scheme is repeated K times, allowing information to propagate K hops across the graph. Because the same parameters are shared across all nodes, GNNs naturally handle graphs of varying size and topology. After K layers, a readout function (e.g., global pooling) can produce a graph‑level embedding for tasks like graph classification, or the final node embeddings can be used for node‑level tasks such as classification or link prediction. The key insight is that relational inductive bias — the assumption that connected nodes influence each other — is baked into the architecture, enabling powerful generalization on structured data.

---

## ✅ Key Points

- Nodes update by aggregating neighbor messages (message passing).
- Aggregation functions are permutation‑invariant (sum, mean, max).
- Parameters are shared across all nodes, enabling variable‑size graphs.
- Stacking K layers yields K‑hop receptive fields.
- Readout/pooling converts node embeddings to graph‑level representations.

## 🏗️ Diagram / Formula

```
h_i^{(k+1)} = σ( W_self * h_i^{(k)} + AGG_{j∈N(i)}( W_neigh * h_j^{(k)} ) )

Layer k=0: input features
Layer k=1: 1‑hop neighborhood
...
Layer K: K‑hop context
Readout:  h_G = POOL({ h_i^{(K)} })
```

## 💡 Real-World Analogy

Think of a GNN like a rumor spreading in a social network: each person updates their belief by listening to friends, and after several rounds everyone’s opinion reflects the broader community.

---

## ⚠️ Common Mistakes

- Using a fixed‑size dense layer on adjacency matrices instead of message passing, losing permutation invariance.
- Forgetting to normalize or weight neighbor contributions, causing exploding/vanishing signals on high‑degree nodes.
- Applying standard CNNs on graph data by flattening adjacency, ignoring the irregular topology.
