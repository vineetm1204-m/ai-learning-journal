# Day 85 — Loss functions: MSE, Cross-Entropy, Huber loss

> 📅 October 10, 2026

---

## 🧠 Concept Explanation

Loss functions quantify how wrong a model's predictions are, guiding optimization via gradients. Mean Squared Error (MSE) computes the average squared difference between predicted and target values: L = (1/n) Σ(ŷ - y)². Its quadratic penalty heavily punishes large errors, making it sensitive to outliers but providing smooth, strong gradients everywhere — ideal for regression where errors are Gaussian-distributed. Cross-Entropy Loss (CE) measures the dissimilarity between two probability distributions: for binary classification, L = -[y log(ŷ) + (1-y) log(1-ŷ)]; for multi-class, L = -Σ y_i log(ŷ_i). It arises naturally from maximum likelihood estimation under a Bernoulli or Categorical likelihood, and its logarithmic shape yields large gradients when confident but wrong, accelerating convergence. Huber Loss blends MSE and MAE: quadratic for small errors (|ŷ-y| ≤ δ) and linear beyond: L = 0.5(ŷ-y)² if |ŷ-y|≤δ else δ|ŷ-y| - 0.5δ². This makes it robust to outliers while retaining differentiability at zero, useful in reinforcement learning and robust regression. Choosing the right loss aligns the optimization objective with the data-generating process and task requirements.

---

## ✅ Key Points

- MSE penalizes large errors quadratically; best for Gaussian noise regression but outlier-sensitive
- Cross-Entropy matches probabilistic outputs; log penalty gives strong gradients for confident mistakes
- Huber Loss transitions from quadratic to linear at threshold δ; robust to outliers, differentiable everywhere
- Loss choice should reflect data distribution (Gaussian → MSE, Bernoulli/Categorical → CE) and outlier tolerance
- All three are differentiable almost everywhere, enabling gradient-based optimization

## 🏗️ Diagram / Formula

```
MSE:        L = 1/n Σ (ŷ - y)²

Cross-Entropy (binary): L = -[y log(ŷ) + (1-y) log(1-ŷ)]
Cross-Entropy (multi):  L = -Σ y_i log(ŷ_i)

Huber (δ):  L = 0.5(ŷ-y)²           if |ŷ-y| ≤ δ
            L = δ|ŷ-y| - 0.5δ²      otherwise
```

## 💡 Real-World Analogy

MSE is like a strict teacher who squares every mistake — small slips are forgiven but big blunders are punished severely. Cross-Entropy is a detective who gets more suspicious the more confidently you lie. Huber is a forgiving mentor who treats small errors gently but caps punishment for catastrophic failures.

---

## ⚠️ Common Mistakes

- Using MSE for classification tasks — it creates non-convex surfaces with poor gradients for probability outputs
- Forgetting to apply softmax/sigmoid before Cross-Entropy, or applying it twice (once in model, once in loss)
- Setting Huber's δ arbitrarily without considering the scale of target values or noise distribution
