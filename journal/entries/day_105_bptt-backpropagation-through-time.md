# Day 105 — BPTT: Backpropagation Through Time

> 📅 November 03, 2026

## 🧠 Concept Explanation

Backpropagation Through Time (BPTT) is the algorithm used to train recurrent neural networks by unfolding the network across time steps and applying the standard backpropagation algorithm on the resulting deep feed‑forward graph. At each time step t the network receives an input x_t, updates its hidden state h_t, and produces an output y_t. The loss L is typically summed over all time steps. To compute gradients of L with respect to the shared parameters (weights W, U, V), we differentiate through the unrolled graph, propagating error signals backward from the final time step to the first. Because the same parameters are reused at every step, gradients from all time steps accumulate, giving each parameter a total gradient that reflects its influence over the entire sequence. In practice, the unrolled graph can become very deep, leading to vanishing or exploding gradients; techniques such as gradient clipping, truncated BPTT, and gated architectures (LSTM, GRU) mitigate these issues. BPTT thus extends the chain rule across temporal dependencies, enabling the network to learn long‑range patterns in sequential data.

---

## ✅ Key Points

- Unrolls the RNN over time to form a deep feed‑forward network.
- Shares parameters across all time steps; gradients accumulate.
- Computes gradients by applying the chain rule backward through time.
- Suffers from vanishing/exploding gradients for long sequences.
- Truncated BPTT and gated units (LSTM/GRU) are common remedies.

## 🏗️ Diagram / Formula

```
x_1 --> [RNN] --> h_1 --> y_1
  |          |          |
  v          v          v
x_2 --> [RNN] --> h_2 --> y_2
  |          |          |
  v          v          v
 ...        ...        ...
  |          |          |
  v          v          v
x_T --> [RNN] --> h_T --> y_T
Loss = sum_t L(y_t, target_t)
Gradients flow backward from T to 1
```

## 💡 Real-World Analogy

BPTT is like a detective reviewing a chronological case file, tracing each clue backward to see how early evidence contributed to the final verdict.

---

## ⚠️ Common Mistakes

- Forgetting to detach hidden states when using truncated BPTT, causing memory leaks.
- Using a learning rate that is too high without gradient clipping, leading to exploding gradients.
- Assuming the network can learn arbitrarily long dependencies without gated mechanisms.
