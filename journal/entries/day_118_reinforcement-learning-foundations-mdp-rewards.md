## 🧠 Concept Explanation

Reinforcement learning (RL) formalizes sequential decision‑making through a Markov Decision Process (MDP). An MDP is a tuple (S, A, P, R, γ) where S is the set of states, A the set of actions, P(s'|s,a) the transition probability of moving to state s' after taking action a in state s, R(s,a,s') the immediate reward received, and γ ∈ [0,1) the discount factor that weights future rewards. The agent follows a policy π(a|s) that maps states to a distribution over actions. The goal is to find an optimal policy π* that maximizes the expected discounted return G_t = Σ_{k=0}^∞ γ^k R_{t+k+1}. Two fundamental value functions capture this objective: the state‑value V^π(s) = E_π[G_t | S_t=s] and the action‑value Q^π(s,a) = E_π[G_t | S_t=s, A_t=a]. The Bellman optimality equations provide recursive relationships: V*(s) = max_a Σ_{s'} P(s'|s,a)[R(s,a,s') + γ V*(s')] and Q*(s,a) = Σ_{s'} P(s'|s,a)[R(s,a,s') + γ max_{a'} Q*(s',a')]. Algorithms such as value iteration, policy iteration, and Q‑learning iteratively approximate these equations to converge to π*.

---

## ✅ Key Points

- MDP defines the environment with states, actions, transition dynamics, rewards, and discount factor.
- A policy π maps states to actions; the optimal policy maximizes expected discounted return.
- Value functions V(s) and Q(s,a) quantify long‑term reward under a policy.
- Bellman equations give recursive consistency conditions for optimal values.
- Dynamic programming and temporal‑difference methods (e.g., Q‑learning) solve MDPs without a model.

## 💡 Real-World Analogy

Think of an MDP like a video game: the screen is the state, the controller buttons are actions, the game engine defines transition probabilities, the score changes are rewards, and the player’s strategy is the policy.

---

## ⚠️ Common Mistakes

- Confusing the policy (mapping states to actions) with the value function (expected return).
- Ignoring the discount factor γ, leading to infinite returns in continuing tasks.
- Assuming the transition model P is known when using model‑free algorithms like Q‑learning.
