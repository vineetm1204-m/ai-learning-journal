# Day 104 — Recurrent Neural Networks (RNN) unrolled through time

## 🧠 Concept Explanation

Recurrent Neural Networks process sequences by feeding the output of a hidden layer back into itself at the next time step. When we “unroll” an RNN through time, we replicate the same cell for each element of the sequence, turning the cyclic graph into a deep feed‑forward network whose depth equals the sequence length. Each copy shares the exact same weights, so the model learns a single transition function that can be applied repeatedly. During forward pass, the hidden state h_t is computed from the current input x_t and the previous hidden state h_{t‑1} using a shared weight matrix and a non‑linearity such as tanh or ReLU. The loss is summed over all time steps, and gradients are back‑propagated through the unrolled graph — a procedure called Backpropagation Through Time (BPTT). Unrolling makes the temporal dependencies explicit, allowing standard automatic‑differentiation tools to compute gradients, but it also reveals the vanishing‑gradient problem: as the chain of multiplications grows, gradients can shrink exponentially, making it hard to learn long‑range patterns. Variants like LSTM and GRU introduce gating mechanisms that preserve gradient flow across many steps. In practice, truncated BPTT limits the unrolled length to a fixed window, trading off memory for the ability to capture moderately long dependencies.

---

## ✅ Key Points

- Unrolling converts the recurrent loop into a deep feed‑forward graph of length T.
- All time steps share the same weight matrices (parameter tying).
- Forward pass computes hidden states sequentially; loss sums over all steps.
- Backpropagation Through Time (BPTT) propagates gradients through the unrolled graph.
- Vanishing/exploding gradients arise from repeated multiplication across many steps.

## 💡 Real-World Analogy

Unrolling an RNN is like reading a book one page at a time while keeping a running summary; each page updates the summary, and the final understanding depends on the entire sequence.

---

## ⚠️ Common Mistakes

- Forgetting to truncate BPTT, causing excessive memory use.
- Treating each time step as independent and not sharing weights.
- Ignoring gradient clipping, leading to exploding gradients.
