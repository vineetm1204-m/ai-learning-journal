## 🧠 Concept Explanation

Feedforward neural networks, often called artificial neural networks (ANNs), are the simplest deep learning architecture. They consist of an input layer that receives raw features, one or more hidden layers that transform the data, and an output layer that produces predictions. Each layer contains units called neurons; every neuron holds a weight vector and a bias scalar. During a forward pass, the input is multiplied by the weight matrix, the bias is added, and a non‑linear activation function (e.g., ReLU, sigmoid) is applied element‑wise. This composition of affine transforms and non‑linearities lets the network approximate any continuous function on a compact domain, a result known as the universal approximation theorem. Training adjusts the weights and biases by minimizing a loss function using gradient‑based optimizers such as stochastic gradient descent. Because information flows only in one direction—from input to output—there are no cycles or recurrence, making the model easy to parallelize on GPUs. Proper initialization, regularization (dropout, weight decay), and careful choice of depth and width are crucial for good generalization. Deeper networks can learn hierarchical representations, where early layers capture simple edges or textures and later layers combine them into complex concepts. However, very deep nets may suffer from vanishing gradients, which can be mitigated by skip connections or batch normalization. Hyperparameter tuning—learning rate, batch size, and architecture size—often determines whether the model converges to a useful solution.

---

## ✅ Key Points

- Layers are fully connected: each neuron receives inputs from all neurons in the previous layer.
- Activation functions (ReLU, sigmoid, tanh) introduce non‑linearity, enabling universal function approximation.
- Forward pass computes output; backward pass (backpropagation) computes gradients for weight updates.
- Depth and width control model capacity; too small underfits, too large overfits without regularization.
- Training uses gradient‑based optimizers (SGD, Adam) on a differentiable loss function.

## 💡 Real-World Analogy

A feedforward network is like an assembly line: raw materials (inputs) pass through a series of workstations (layers), each adding a transformation, until a finished product (prediction) emerges at the end.

---

## ⚠️ Common Mistakes

- Using linear activations only, which collapses the network to a single linear model.
- Ignoring weight initialization, leading to vanishing or exploding gradients.
- Choosing an excessively large network without regularization, causing severe overfitting.
