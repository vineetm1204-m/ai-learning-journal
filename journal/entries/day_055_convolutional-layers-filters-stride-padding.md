# Day 55 — Convolutional layers: filters, stride, padding

> 📅 August 22, 2026

## 🧠 Concept Explanation

A convolutional layer slides a set of learnable filters (also called kernels) across an input tensor, typically an image or feature map. Each filter is a small 3‑D tensor (height × width × input_channels) that performs an element‑wise multiplication with the receptive field it covers, then sums the results to produce a single scalar. Repeating this for every spatial position yields a 2‑D activation map per filter; stacking all filters gives the layer's output volume. Stride controls how many pixels the filter jumps each step: stride = 1 moves one pixel, stride = 2 skips every other pixel, reducing spatial resolution. Padding adds extra border pixels (usually zeros) around the input so that the output can retain the same spatial size ("same" padding) or to prevent rapid shrinking. Together, filters, stride, and padding determine the receptive field growth, computational cost, and the amount of spatial information preserved. Convolution exploits locality and weight sharing, dramatically reducing parameters compared to fully‑connected layers while capturing translation‑invariant patterns such as edges, textures, and object parts.

---

## ✅ Key Points

- Filters are small learnable tensors that detect local patterns via dot‑product with input patches.
- Stride defines the step size of the sliding window; larger stride downsamples the feature map.
- Padding (zero‑padding) preserves spatial dimensions or controls output size.
- Weight sharing across positions makes convolution parameter‑efficient and translation‑equivariant.
- Stacking multiple filters creates depth, allowing the network to learn hierarchical features.

## 🏗️ Diagram / Formula

```
Input (H×W×C_in)  --[filter K×K×C_in]-->  Output (H_out×W_out×C_out)
H_out = floor((H + 2*pad - K) / stride) + 1
W_out = floor((W + 2*pad - K) / stride) + 1
```

## 💡 Real-World Analogy

Imagine a flashlight (filter) scanning a wall mural (input); the beam size is the kernel, the step you move the flashlight is the stride, and taping a white border around the mural is padding so the flashlight never falls off the edge.

---

## ⚠️ Common Mistakes

- Forgetting to account for padding when computing output dimensions, leading to shape mismatches.
- Using a stride larger than the kernel size without realizing it discards information.
- Initializing all filters identically (e.g., zeros), which prevents learning diverse features.
