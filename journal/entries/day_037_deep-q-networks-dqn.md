# Day 37 — Deep Q-Networks (DQN)

## 🧠 Concept Explanation

Deep Q-Networks (DQN) revolutionized reinforcement learning by combining Q-learning with deep neural networks, enabling agents to learn directly from high-dimensional sensory inputs like raw pixels. Traditional Q-learning stores a table of state-action values, which becomes infeasible for large or continuous state spaces. DQN replaces this table with a neural network that takes the state as input and outputs Q-values for all possible actions. Two key innovations stabilize training: experience replay and target networks. Experience replay stores transitions (state, action, reward, next state) in a buffer and samples mini-batches randomly, breaking temporal correlations and improving data efficiency. Target networks provide fixed Q-value targets for a number of steps by using a separate network with periodically copied weights, preventing the moving target problem that causes divergence. The loss function minimizes the squared difference between predicted Q-values and target Q-values derived from the Bellman equation: target = reward + gamma * max_a' Q_target(next_state, a'). An epsilon-greedy policy balances exploration and exploitation. DQN achieved human-level performance on many Atari games, demonstrating that deep RL can master complex tasks from pixels alone.

---

## ✅ Key Points

- Experience replay buffer decorrelates sequential data and enables off-policy learning
- Target network with periodically frozen weights stabilizes Q-value targets
- Epsilon-greedy exploration decays over time to shift from exploration to exploitation
- Huber loss reduces sensitivity to outliers compared to MSE
- Double DQN extension mitigates overestimation bias by decoupling action selection and evaluation

## 💡 Real-World Analogy

DQN is like a gamer who records every gameplay moment in a diary (experience replay), reviews random past entries to learn patterns, and only updates their strategy guide (target network) every few levels to avoid constantly changing tactics mid-game.

---

## ⚠️ Common Mistakes

- Omitting the target network, causing unstable Q-value targets and divergence
- Skipping experience replay, leading to correlated samples and catastrophic forgetting
- Using a fixed high epsilon or decaying too slowly, preventing convergence to optimal policy
