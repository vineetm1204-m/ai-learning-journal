## 🧠 Concept Explanation

Gated Recurrent Units (GRU) are a streamlined variant of Long Short‑Term Memory networks designed to capture temporal dependencies with fewer parameters. Like LSTMs, GRUs maintain a hidden state that flows through time, but they replace the separate input, forget, and output gates with just two gates: an update gate and a reset gate. The update gate decides how much of the previous hidden state should be carried forward, effectively blending the old memory with the new candidate activation. The reset gate controls how much of the past hidden state contributes to the candidate activation, allowing the model to drop irrelevant information. The candidate hidden state is computed using the reset‑gated previous state and the current input, then the final hidden state is a convex combination of the previous hidden state and the candidate, weighted by the update gate. This gating mechanism lets GRUs learn long‑range dependencies while being computationally cheaper and easier to train than LSTMs. In practice, GRUs often match LSTM performance on sequence tasks such as language modeling, speech recognition, and time‑series forecasting, especially when data is limited. Their simpler architecture also reduces the risk of overfitting on small datasets and speeds up inference on mobile devices. This makes them a popular default choice for many practitioners.

---

## ✅ Key Points

- Two gates (update and reset) replace LSTM's three gates.
- Update gate blends previous hidden state with new candidate.
- Reset gate determines how much past information to forget when computing candidate.
- Fewer parameters → faster training and lower memory footprint.
- Often matches LSTM performance on many sequence tasks.

## 🏗️ Diagram / Formula

```
x_t -->[reset gate]--> r_t
x_t -->[update gate]--> z_t
h_{t-1} -->[reset]--> r_t * h_{t-1}
candidate = tanh(W * [r_t * h_{t-1}, x_t] + b)
h_t = (1 - z_t) * h_{t-1} + z_t * candidate
```

## 💡 Real-World Analogy

A GRU is like a notebook where you decide each day how much of yesterday's notes to keep (update gate) and which old notes to discard before writing today's summary (reset gate).

---

## ⚠️ Common Mistakes

- Confusing the roles of the update and reset gates.
- Using GRU without proper weight initialization, leading to vanishing gradients.
- Assuming GRU always outperforms LSTM and skipping hyperparameter tuning.
