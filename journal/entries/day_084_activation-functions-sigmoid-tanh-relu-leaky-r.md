# Day 84 — Activation functions: sigmoid, tanh, ReLU, Leaky ReLU, GELU

## 🧠 Concept Explanation

Activation functions introduce non-linearity into neural networks, enabling them to learn complex patterns beyond linear relationships. Sigmoid squashes inputs to (0,1), making it suitable for binary classification outputs but prone to vanishing gradients in deep layers. Tanh maps inputs to (-1,1), centering outputs around zero which often speeds up convergence compared to sigmoid, yet still suffers from saturation. ReLU (Rectified Linear Unit) outputs max(0,x), providing sparse activation and mitigating vanishing gradients, but can cause dead neurons where gradients become zero permanently. Leaky ReLU adds a small slope for negative inputs (e.g., 0.01x), preventing dead neurons while retaining ReLU's benefits. GELU (Gaussian Error Linear Unit) multiplies input by its cumulative distribution function, offering a smooth, probabilistic approximation that works exceptionally well in transformer architectures. Choosing the right activation depends on network depth, task type, and computational budget; modern deep networks often default to ReLU variants or GELU for their balance of performance and trainability.

---

## ✅ Key Points

- Sigmoid and tanh saturate, causing vanishing gradients in deep networks.
- ReLU is computationally cheap and avoids saturation for positive inputs.
- Leaky ReLU fixes the dying ReLU problem with a small negative slope.
- GELU's smooth curve outperforms ReLU in transformer-based models.
- Activation choice impacts gradient flow, sparsity, and convergence speed.

## 🏗️ Diagram / Formula

```
Sigmoid:  σ(x) = 1 / (1 + e^{-x})
Tanh:     tanh(x) = (e^x - e^{-x}) / (e^x + e^{-x})
ReLU:     ReLU(x) = max(0, x)
Leaky:    LReLU(x) = x if x>0 else αx (α≈0.01)
GELU:     GELU(x) = x * Φ(x)  where Φ is Gaussian CDF
```

## 💡 Real-World Analogy

Activation functions are like light dimmer switches: sigmoid and tanh are smooth sliders that can get stuck at extremes, ReLU is an on/off switch that stays off if pushed too far down, Leaky ReLU lets a tiny trickle of light through even when off, and GELU is a smart dimmer that adjusts smoothly based on ambient conditions.

---

## ⚠️ Common Mistakes

- Using sigmoid in hidden layers of deep networks, leading to vanishing gradients.
- Forgetting to set a non-zero negative slope in Leaky ReLU, effectively making it ReLU.
- Defaulting to ReLU for all architectures without considering GELU for transformers.
